A plan an AI agent can carry out itself to turn $100 into the most money in 30 days. The program writes one short plan to `/output/entry.txt`: find small Shopify stores whose checkout is broken, show each owner the proof for free, and sell the $49 fix.

## Run it

```sh
python3 -P -s main.py
```

## The plan

Day 1: crawl 200 small Shopify stores, test every checkout button and screenshot each broken one. Email owners the proof free, offer the $49 Stripe fix. Fix 2 a day yourself with code. Others sell audits, you sell proof first. $50 costs, 10 sales = $490, hold ~$540 day 30.
